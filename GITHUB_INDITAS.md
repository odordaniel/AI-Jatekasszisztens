# GitHub közzététel – rövid útmutató

1. Olvasd el a `SIGNPATH_JELENTKEZES.md` fájlt.
2. Dönts a licencről. A LICENSE szándékosan hiányzik, mert a szerzőnek kell jóváhagynia a licencet.
3. Hozz létre nyilvános `AI-Jatekasszisztens` repositoryt a GitHubon.
4. A **belső** `AI_Jatekasszisztens_Portable_v1_9` mappa tartalmát töltsd a repository gyökerébe.
5. Az Actions fülön ellenőrizd a `Windows portable build` workflow-t.
6. A build artifact jelenleg aláíratlan; ne terjeszd aláírtként.
7. A SignPath Foundation jelentkezést a licenc, biztonsági ellenőrzés, teszt és kiadási dokumentáció után indítsd.

A meglévő `src/assistant.py`, `src/app.ico`, `requirements.txt`, `build_portable.*`, README és AI-fejlesztői dokumentáció változatlan.
